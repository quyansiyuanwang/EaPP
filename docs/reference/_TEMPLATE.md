# 参考页模板

> **这是模板，不是文档。** 复制它来新建实体参考页；`_TEMPLATE.md` 本身不进索引。
>
> 每页不超过 60 行。本模板的正文结构就是页面结构：元数据表 · 语义 · 常见误用 · 相关。

---

# 实体名

用一行写清它是什么，不超过 30 字。不要加"一句话："之类的前缀 ——
`check-docs` 的语域规则会把行首的"一句话："判为修辞性收束（[`docs/STYLE.md`](../STYLE.md) §5）。

| | |
|---|---|
| **层** | Composition Core / Interaction Layer / State Mode / 插件开发表面 |
| **规范** | 定义它的 §号，例如 `§9`、`§22.1` |
| **不变量** | 前缀与范围，例如 `B-1…B-9`；没有就写 `—` |
| **稳定度** | FROZEN |

## 语义

3–8 行。只解释规范说了什么。

**不要复述字段表。** 字段表在规范正文里，复述会随规范一起漂移 ——
参考页的职责是索引，不是副本。需要图示时用围栏代码块。

```
A ──► B
```

## 常见误用

至少 1 条，最多 4 条。每条引用规范条款 ID 或 §号：

- "`Binding` 的 `PENDING` MUST NOT 对外可观察（`B-9`）。"

找不到可引条款时，改写为"最容易与哪个相邻概念混淆"，并给出区分二者的 §号。

## 写作规则

1. **不复述规范正文。** 规范是唯一的规范性来源；这一页索引它、解释它。冲突时以规范为准。
2. **§号与不变量 ID 必须能在 [`docs/spec/eapp.md`](../spec/eapp.md) 中查到。** 不得发明 API。
3. **不使用第二人称**，不写口语化措辞（[`docs/STYLE.md`](../STYLE.md) §5）。
4. **链接只用相对路径**，且每一条都必须落到真实文件（[`docs/STYLE.md`](../STYLE.md) §6）。
