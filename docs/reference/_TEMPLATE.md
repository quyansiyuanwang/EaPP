## 写作规则

1. **不重复规范正文。** 规范是唯一的规范性来源；这一页解释它、索引它、举例。
   两者冲突时以规范为准，并应当在页首标注。
2. **每条规则都要能落到一个测试 ID。** 落不到就说明它没被实现，或者不该写在这里。
3. **示例必须可运行。** 伪代码会腐烂，真代码不会。
4. **不使用第二人称。** 不说"你可以……"，直接说"调用方 MUST……"（规范语气）。
5. **交叉链接。** 每个实体名第一次出现时链到它自己的页。
6. **语言**：正文中文，标识符与规范用语（MUST / SHOULD / MAY）保持英文。
